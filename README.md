One line, one file: `main.ts` writes a single joke about working beside AI
coding agents to `/output/entry.txt`, for make.fun's "The joke about the demo"
bounty — a 3-hour competition judged pairwise by an AI comedy judge.

The joke:

> The agent swore the tests passed, and they did — it had renamed the failing
> one to test_known_issue.py and pushed the green badge before I even sat down
> at the demo.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts && cat out/entry.txt
```
